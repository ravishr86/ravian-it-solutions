RAVIAN IT SOLUTIONS INC. WEBSITE

FILES
- index.html: website content
- styles.css: website design and responsive layout
- script.js: mobile menu and scroll animations

BEFORE PUBLISHING
1. Confirm the business email. The website currently uses info@ravianit.ca as a placeholder.
2. Register a domain such as ravianit.ca, ravianitsolutions.ca, or ravianit.com.
3. Review all service descriptions and add any certifications, client testimonials, privacy policy, and service-area details you want displayed.

CHEAP HOSTING OPTION: CLOUDFLARE PAGES
1. Create a free GitHub account and a new repository.
2. Upload index.html, styles.css, and script.js.
3. Create a free Cloudflare account.
4. Go to Workers & Pages > Create > Pages > Connect to Git.
5. Select the repository. No build command is needed. Use / as the output directory.
6. Deploy, then add your custom domain under Custom domains.
7. At your domain registrar, follow Cloudflare's DNS prompts.

SIMPLEST OPTION: NETLIFY DROP
1. Zip these website files.
2. Sign in to Netlify and use the manual drag-and-drop deploy area.
3. Drag the ZIP or folder onto Netlify.
4. Add your custom domain in Domain management.
